System Architecture

Modular Kotlin architecture wired with Hilt dependency injection and Room persistence.

Hybrid Inference Engine

GeminiCloudEngine (OkHttp SSE streaming + native function calling) combined with LiteRtLmEngine for on-device execution and HybridInferenceRouter for RAM, battery, thermal, and feedback-aware routing.

Autonomous Agent Loop

AutonomousAgentEngine runs a bounded Plan → Tool Call → Observation → Verification → Recovery cycle with Room task persistence across runs.

Confirmation Gates

Sensitive device actions — call_phone, compose_message, write_workspace_file, and save_memory — require explicit user approval.

Memory & Feedback Learning

Room SQLite with FTS4 full-text search (MemoryRepository), conversation logs (ConversationRepository), and trace/feedback scoring (LearningRepository) — no false weight-training claims.

Voice & Background

SpeechRecognizerManager and TextToSpeechManager for hands-free voice workflows, backed by AgentForegroundService and WorkManager downloads.

Encrypted Secret Vault

Runtime API keys entered in Settings are encrypted at rest with AES-256-GCM through AndroidKeyStore (SecretVault).

Configuration & Offline Mode

Bring your own Gemini API key and/or local .litertlm weights.

1. Gemini API Configuration

Open Settings inside the app and enter your Gemini API key. It is stored locally and encrypted with AES-256-GCM via AndroidKeyStore.

For local builds, you may optionally place GEMINI_API_KEY=... inside your git-ignored local.properties file.

2. Local Model Setup (Offline Mode)

Offline inference requires a real .litertlm model file on-device — the app never simulates offline responses.

Open the Models tab, tap Download (via WorkManager) or Import File via Storage Access Framework, then pick GPU, CPU, or NPU.
